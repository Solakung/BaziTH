# BaziTH

ตำราและไลบรารีคำนวณปาจื้อ (八字 สี่เสา) สำหรับสร้างแอปดูดวงภาษาไทย คำนวณสี่เสาจากตำแหน่งดวงอาทิตย์จริง รองรับเวลาประเทศไทย เวลาสุริยะจริง และ พ.ศ. ไม่มี dependency

**เว็บ:** https://solakung.github.io/BaziTH/ (หน้าผังดวง) · https://solakung.github.io/BaziTH/guide.html (ปาจื้อสำหรับมือใหม่) · https://solakung.github.io/BaziTH/textbook.html (หน้าอ่านตำรา)

หน้าผังดวงแสดงผลสามแท็บ

- **อ่านง่าย** สำหรับคนที่ไม่เคยเรียนปาจื้อ สรุปตัวตน พลังในตัว ธาตุที่ช่วย ช่วง 10 ปี และปีนี้กับปีหน้าเป็นภาษาธรรมดา
- **ถามดวง** เลือกเรื่อง (ภาพรวม ความรัก การงาน การเงิน การเรียน สุขภาพ คนรอบตัว เดินทาง) กับช่วงเวลา หรือพิมพ์คำถามภาษาไทย แล้วเปิดไพ่ 3 ใบ คือพื้นดวง ช่วงชีวิต และช่วงที่ถาม ได้แนวโน้ม 5 ระดับ สิ่งที่ทำได้ และเหตุผลทุกข้อ ไม่มีการสุ่ม และไม่ทำนายความตาย โรค การตั้งครรภ์ ผลคดี เลขเสี่ยงโชค หรือจังหวะลงทุน
- **ละเอียด** ศัพท์จริงและตัวเลขทุกขั้นสำหรับผู้ศึกษา

## เปิดหน้าเว็บบนเครื่อง

หน้าเว็บใช้ ES module จึงเปิดไฟล์ `index.html` ด้วยการดับเบิลคลิกตรง ๆ ไม่ได้ ต้องผ่านเว็บเซิร์ฟเวอร์

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

ไฟล์ `.nojekyll` สั่งให้ GitHub Pages ส่งไฟล์ตามที่เป็นอยู่ ไม่ต้องผ่าน Jekyll

## เริ่มใช้

```javascript
import { computeChart, analyze, luckPillars } from './src/bazi-core.js';

const chart = computeChart({
  year: 1995, month: 3, day: 15, hour: 14, minute: 30,
  timeZone: 'Asia/Bangkok',
  gender: 'M',
  // longitude: 100.5,       // ใส่เมื่อต้องการใช้เวลาสุริยะจริง
  // lateZiRule: 'sameDay',  // สำนักยามชวดดึก (ค่าเริ่มต้น 'nextDay')
});

chart.names;          // { year: '乙亥', month: '己卯', day: '乙巳', hour: '癸未' }
chart.warnings;       // คำเตือนเมื่อเกิดใกล้รอยต่อสารทหรือรอยต่อยาม
analyze(chart);       // ก้านแฝง สิบเทพ ความสัมพันธ์ กำลังเจ้าวัน ธาตุให้คุณ ดาวพิเศษ
luckPillars(chart);   // วัยจร 10 ปี: ทิศทาง วันเริ่ม และ 8 เสาแรก
```

ไม่ทราบเวลาเกิดให้ส่ง `hour: null` จะได้ผังสามเสา ใช้ในเบราว์เซอร์ได้ด้วย `<script type="module">` โดยตรง

## ความแม่นยำ

- เวลาสารทคำนวณด้วย VSOP87 แบบย่อตามตำรา Meeus เทียบกับ[ตารางหอดูดาวฮ่องกงปี 2026](https://my.weather.gov.hk/en/gts/astron2026/files/2026SolarTerms24.pdf)แล้วคลาดไม่เกิน 0.6 นาที
- เสาปีและเสาเดือนเปลี่ยนถูกต้องทุกรอยต่อสารทระหว่าง ค.ศ. 1900–2100 รวม 2,412 จุด
- ยังไม่ได้เทียบกับไลบรารีภายนอก เช่น lunar-javascript ควรเทียบเพิ่มก่อนเปิดใช้จริง
- ส่วนวิเคราะห์ (กำลังเจ้าวัน ธาตุให้คุณ) เป็นกฎตั้งต้นรุ่นแรก ควรให้ผู้รู้ปรับเกณฑ์ ดูบทที่ 11–12 ในตำรา
- คำอ่านในแท็บอ่านง่ายและถามดวงเลือกจากกฎ ไม่มีการสุ่ม ใช้น้ำหนักปีจรตามบทที่ 15.2 (ก้าน 0.4 กิ่ง 0.6) ส่วนเกณฑ์ 5 ระดับตั้งจากการกระจายของผังสุ่ม ทุกคำตอบกดดู "ทำไมได้คำตอบนี้" ได้ ข้อความยังต้องให้ผู้รู้ตรวจ
- ผังที่แข็งมากหรืออ่อนมาก สองสำนักให้ธาตุให้คุณต่างกัน (บทที่ 12) แท็บอ่านง่ายและถามดวงจึงนับเฉพาะธาตุที่ทุกแนวเห็นตรงกัน และแสดงทั้งสองแนวให้เห็น

## ข้อควรรู้

ปาจื้อเป็นศาสตร์ความเชื่อ ไม่มีหลักฐานทางวิทยาศาสตร์ว่าทำนายชีวิตได้ แอปที่สร้างจาก repo นี้ควรวางตัวเป็นความบันเทิงและเครื่องมือสะท้อนตัวเอง ดูแนวทางในบทที่ 18 ของตำรา
